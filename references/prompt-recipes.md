# Imagegen 提示模板

## 变量表

调用前替换所有方括号内容：

- `[主体]`
- `[物种/类别]`
- `[品种/子类；不适用时填“无”]`
- `[必须保留的身份特征：少量关键识别点及用户明确锁定项，不自动包含全部真实结构]`
- `[形体方案：2–5 个主要形状、比例关系、要省略或合并的结构细节]`
- `[动作或姿势]`、`[神态]`、`[一个主特征]`
- `[动作/成就含义/叙事情境]`
- `[产品气质或功能]`、`[图标第一识别层]`
- `[关键道具]`、`[2–5 个环境线索]`
- `[主色板与背景]`
- `[比例]`
- `[真实目标像素尺寸]`
- `[用途]`
- `[平台；不适用时填“无”]`
- `[导出格式、背景实色/透明、alpha 与平台圆角规则]`
- `[徽章数字表达：无，或一个作为主符号的 1–2 位数字]`
- `[参考图分工：哪张是身份参考，哪张是风格参考]`

实际调用时，在提示词中用“不可妥协的风格要求”明确标注并带入 `SKILL.md` 的六条硬门槛；不能只附文件名，不能用下列通用风格段代替硬门槛。随后补充本次主体、形体方案及交付变量。

通用风格段可复用：

> 将主体重新设计成稚拙的手绘形象，像凭印象用几块不规则形状画出来。先重构形体：以团块、钝楔形和长短条组织大小、宽窄及连接关系，省略非必要的结构转折和透视交代。形体方案：[形体方案]。去掉纹理后，造型本身仍应明显概括、略显笨拙，不能只给自然比例的形象换上水粉材质。用少量完整的大形和 3–6 个主要颜色建立识别，轮廓略钝，弧段不等宽、局部偏心，接合略显生硬但清楚；避免处处顺滑、重复尖角和整齐裁切的花边，不用均匀抖动替代形状变化。比例有一个主导的设计关系，其余部位随之概括。细节用少量形状和笔触提示，避免精细描摹和真实比例复刻。允许局部深浅、接触暗部及叠色丰富大形，不建立完整写实光照，也不抹平所有明暗。采用厚实、有覆盖感的不透明水粉色块，内部保留叠擦、局部露底和不均匀颜料肌理；笔触以颜料叠擦为主，方向、长短、疏密自然变化，可交错或中断；允许局部顺形，不连续梳理整个表面来解释材质、曲率或体积，不堆砌零碎细节，不用全图噪点滤镜。神态与动作随内容变化，通过简练而鲜明的形体关系表达。保留主体关键识别特征及其关系，以统一的手绘语言重新组织；不继承风格参考中的物种、表情、配色或构图。无三维渲染、光滑矢量边缘或巨眼腮红式卖萌。

## 整体过于精致或拟实时

不要直接使用下面的局部编辑模板锁住原图比例和轮廓。附上原图作为内容参考，并实际传入风格锚点，追加：

```text
本轮是形体重构，不是纹理润色。只保留：[关键识别点、用户认可内容和明确锁定项]。
重新设计：[形体方案]。允许联动改变轮廓、比例、局部结构与塑形笔触；不要沿失败图的真实轮廓描摹。
成功标准：遮去肌理、阴影和表面细节后，仅凭大形与部件关系仍能看出稚拙风格。神态与动作遵从本次内容要求。
```

## 大形已概括但仍太规整时

保留已认可的大形、识别点和简化程度，联动调整轮廓节奏、局部接合和笔触组织，不必继续删细节或整体重构：

```text
保留：[已认可的大形、比例及内容]。本轮调整手画的自然不规则性：少量弧段变得不等宽、轻微偏心，接合不处处圆滑；边界变化不等距、不重复，不增加整圈锯齿或随机毛边。笔触以交错、断续的颜料叠擦为主，减少连续顺形梳理。保留局部明暗和肌理层次。不要把简化推成几何剪纸，也不要恢复精细拟实刻画。
```

## 局部编辑已有图像时追加

```text
这是局部定向编辑。锁定并保持不变：[已认可的构图、比例、色板、纹理、姿势或其他特征]。
本轮只修改：[一个变量]，目标是[可观察结果]。不得借机增加细节、改变风格强度或重画无关区域。
```
