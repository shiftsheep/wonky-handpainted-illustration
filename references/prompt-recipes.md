# Imagegen 提示模板

## 变量表

调用前替换所有方括号内容：

- `[主体]`
- `[物种/类别]`
- `[品种/子类；不适用时填“无”]`
- `[必须保留的身份特征：结构、花纹准确位置、颜色、神态、服饰或道具]`
- `[动作或姿势]`、`[神态]`、`[一个主特征]`
- `[动作/成就含义/叙事情境]`
- `[产品气质或功能]`、`[图标第一识别层]`
- `[关键道具]`、`[2–5 个环境线索]`
- `[主色板与背景]`
- `[比例]`
- `[真实目标像素尺寸]`
- `[用途]`
- `[平台；不适用时填“无”]`
- `[导出格式、背景实色/透明、alpha 与平台圆角规则]`
- `[徽章数字表达：无，或一个作为主符号的 1–2 位数字]`
- `[参考图分工：哪张是身份参考，哪张是风格参考]`

通用风格段可复用：

> 可爱但不幼稚的粗拙平面手绘插画。轮廓略歪、略钝、左右不完全对称，比例只有一处克制夸张；使用 3–6 个平面色块、干水粉与蜡笔般的断续笔触，允许轻微漏白、覆盖不均和色块错位。纹理来自实际笔触，不使用全图噪点滤镜。无写实毛发、无三维渲染、无复杂渐变、无光滑矢量边缘、无巨眼腮红式卖萌。优先准确保留用户指定的物种、品种和身份特征。

## 角色形象模板

```text
生成一幅比例为[比例]、真实目标像素尺寸为[真实目标像素尺寸]、用于[用途]的单角色形象。主体：[主体]；物种/类别：[物种/类别]；品种/子类：[品种/子类；不适用时填“无”]。
必须准确保留：[必须保留的身份特征]。角色正在[动作或姿势]，神态[神态]。
构图以清晰完整的单一剪影为主，背景简洁；用头部轮廓、眼距、主花纹和主色建立识别，不依赖细碎线条。
[通用风格段]
配色：[主色板与背景]。只夸张[一个主特征]，其余结构克制。
[参考图分工]。风格不得覆盖、移动、合并或删减上述身份特征。
交付：[导出格式、背景实色/透明、alpha 与平台圆角规则]。在真实目标像素导出后检查，至少保留两个相互独立的主体/物种识别特征。
```

## 成就徽章模板

```text
生成一枚比例为[比例]、真实目标像素尺寸为[真实目标像素尺寸]、用于[用途]的成就徽章。成就含义：[动作/成就含义]；主体：[主体]；物种/类别：[物种/类别]；品种/子类：[品种/子类；不适用时填“无”]。
必须准确保留：[必须保留的身份特征]。主体采用一个清晰动作或符号，置于略不规则、像手剪或手印的简单底形内，辅助符号最多两个。
构图层级：先读懂成就含义，再认出主体，最后看到装饰；不要画成缩小的场景。
[通用风格段]
配色：[主色板与背景]。数字表达：[徽章数字表达：无，或一个作为主符号的 1–2 位数字]；禁止小段文字，若使用数字，它必须醒目并承担核心成就语义。按真实导出的 32–64 px 检查，关键线宽与色块间隙建议至少约 2 px；控制内部孔洞、交叉线和边框层数。无写实金属、无复杂纹章。
[参考图分工]。风格不得覆盖主体身份和成就含义。
交付：[导出格式、背景实色/透明、alpha 与平台圆角规则]。若含角色或物种，缩小后至少保留两个相互独立的识别特征。
```

## APP Icon 模板

```text
生成一枚用于[平台；不适用时填“无”]、真实目标像素尺寸为[真实目标像素尺寸]、产品用途为[用途]的 APP Icon。主体：[主体]；物种/类别：[物种/类别]；品种/子类：[品种/子类；不适用时填“无”]；表达[产品气质或功能]。
必须准确保留：[必须保留的身份特征]。使用单主体大特写，占安全区约 65%–80%，以[图标第一识别层]作为第一识别层，背景为一个大色块并预留平台裁切空间。圆角蒙版和 alpha 按用户平台规则处理，不自行烘焙系统圆角。
[通用风格段]
配色：[主色板与背景]。按真实导出的 1024 px、180 px、60 px 和约 32 px 检查；小尺寸下五官不粘连、身份花纹不丢失、前景背景有明确明度差，并至少保留两个相互独立的主体/物种识别特征。
无文字、无细边框、无多角色、无场景背景、无未经平台要求的透明边缘或圆角蒙版。
[参考图分工]。不要把完整插画机械缩小，按图标重新构图。
交付：[导出格式、背景实色/透明、alpha 与平台圆角规则]。
```

## 单幅／场景插画模板

```text
生成一幅比例为[比例]、真实目标像素尺寸为[真实目标像素尺寸]、用于[用途]的场景插画。主体：[主体]；物种/类别：[物种/类别]；品种/子类：[品种/子类；不适用时填“无”]。它在[叙事情境]中[主叙事动作]。
必须准确保留：[必须保留的身份特征]。画面只有一个视觉焦点；关键道具是[关键道具]，环境仅用[2–5 个环境线索]说明地点、时间或情绪，并保留大面积负空间。
[通用风格段]
配色：[主色板与背景]。用不规则大色块组织空间，不追求写实透视；背景纹理弱于主体，缩略图中首先读到主角、动作和色彩节奏。
无复杂光影、无均匀铺满的小物、无各处同等细节。
[参考图分工]。身份特征与叙事信息优先于风格装饰。
交付：[导出格式、背景实色/透明、alpha 与平台圆角规则]。在真实目标像素导出后检查；含角色或物种时至少保留两个相互独立的识别特征。
```

```text
这是局部定向编辑。锁定并保持不变：[已认可的构图、比例、色板、纹理、姿势或其他特征]。
本轮只修改：[一个变量]，目标是[可观察结果]。不得借机增加细节、改变风格强度或重画无关区域。
```
